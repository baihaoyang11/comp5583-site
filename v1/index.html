Everything I know about this came from coursework I had to debug myself, so I trust a small experiment I can rerun more than a large claim I cannot.

02Projects

Coursework

Four models, two datasets — digits and multilingual toxicity

Four models that are usually described separately, run under one protocol each: on Digits4000 a hand-written NumPy MLP and a PyTorch CNN, on multilingual toxicity a TF-IDF + logistic regression baseline and a fine-tuned multilingual DistilBERT. Two datasets, so the digit models are tabulated and the toxicity results are given as numbers in prose — four models from two datasets in one table is how a page ends up promising a comparison it cannot make.

My contribution. Implemented the MLP and its backward pass by hand, with no automatic differentiation. Built two independently seeded corruption suites (Gaussian noise σ = 0.2, rotation ±15°) so that the CNN and the MLP could be compared on inputs neither had seen. Ran the DistilBERT fine-tuning and the threshold protocol, ran the loss ablation, and wrote the report.

Test accuracy on 2000 images. Both models were evaluated on the same corrupted sets and neither was retrained on corrupted data, so the drop is a measure of robustness, not of extra training. The CNN lost 0.0185 to pixel noise against the MLP's 0.0130, and 0.0160 to rotation against 0.0205 — so "more robust" depends on which corruption you mean, and neither model wins both.

Multilingual toxicity

The other two models were not on digits, so they do not belong in that table. On 4000 test comments, 615 of them toxic, TF-IDF with logistic regression reached a ROC-AUC of 0.5796 and an F1 of 0.1645 on the toxic class; the fine-tuned multilingual DistilBERT reached 0.7638 and 0.3236. Then the part that matters: dropping the inverse-frequency class weighting I had chosen lifted that F1 to 0.4957 and the AUC to 0.7812.

So the model I shipped was beaten by the model I rejected. The weighting raised recall from 0.35 to 0.87 and cut precision from 0.58 to 0.20, which moves the operating point rather than improving the classifier, and F1 fell 0.17 because of it. The decision threshold was fixed on the English validation set in every run and never on the test set, so this is not threshold shopping — it is a loss function I should not have used.

Everything above ran on 27 October 2026, seed 42, torch 2.8.0+cu126 on one laptop GPU: 2 s for the MLP, 25 s for the CNN, 189 s for the toxicity pipeline including the ablation. The numbers are read from the result files (task2_summary, task3_summary, ablation_unweighted) rather than typed from memory — which is why one of them is allowed to contradict the decision it describes.

Proposed

Citation-first Q&A over course notes

Answer questions over my own lecture PDFs so that every sentence in the answer points at the passage it came from. The point is to be able to check the answer, not to trust it.

Planned contribution. Chunking by section heading, hybrid BM25 + dense retrieval, and a 40-question evaluation set built from questions I have actually asked. Measure answer correctness and citation precision with and without retrieval, so that the retrieval step has to justify itself.

Because the evaluation set is the part I have not finished. A retrieval demo without a fixed question set only shows that retrieval returns something; it cannot show that the returned passage is the one that supports the answer. I would rather label this as a proposal than ship a demo that cannot fail.
