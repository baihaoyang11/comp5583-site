Interests

I came into this programme from the engineering side, and the part I actually enjoy is what happens after the demo works: finding out why it stops working when the data changes. At the moment that means retrieval systems whose answers can be checked against the passage they came from, evaluation that still means something on a different dataset, and the unglamorous work of making a model usable by someone who did not write it.

Everything I know about this came from coursework I had to debug myself, so I trust a small experiment I can rerun more than a large claim I cannot.

02Projects

Coursework

Four models, one split — Digits4000 and multilingual toxicity

Compare four models that are usually described separately, under one fixed protocol: a hand-written NumPy MLP, a PyTorch CNN, a fine-tuned multilingual DistilBERT, and a TF-IDF + logistic regression baseline. Stratified 80/20 split, test set read once.

My contribution. Implemented the MLP and its backward pass by hand, with no automatic differentiation. Built two independently seeded corruption suites (Gaussian noise σ = 0.2, rotation ±15°) so that the CNN and the MLP could be compared on inputs neither had seen. Ran the DistilBERT fine-tuning and the threshold protocol, and wrote the report.

Test accuracy of the four models
ModelCleanNoisyRotated
NumPy MLP0.92750.91450.9070
PyTorch CNN0.96000.94150.9440

Test accuracy on 2000 images. Both models were evaluated on the same corrupted sets and neither was retrained on corrupted data, so the drop is a measure of robustness, not of extra training.

The ranking was the boring part. What mattered was that the two models degraded differently — the CNN lost 0.0185 to pixel noise and 0.0160 to rotation, the MLP lost 0.0130 and 0.0205 — so "more robust" depends on which corruption you mean.

Proposed

Citation-first Q&A over course notes

Answer questions over my own lecture PDFs so that every sentence in the answer points at the passage it came from. The point is to be able to check the answer, not to trust it.

Planned contribution. Chunking by section heading, hybrid BM25 + dense retrieval, and a 40-question evaluation set built from questions I have actually asked. Measure answer correctness and citation precision with and without retrieval, so that the retrieval step has to justify itself.

Because the evaluation set is the part I have not finished. A retrieval demo without a fixed question set only shows that retrieval returns something; it cannot show that the returned passage is the one that supports the answer. I would rather label this as a proposal than ship a demo that cannot fail.
